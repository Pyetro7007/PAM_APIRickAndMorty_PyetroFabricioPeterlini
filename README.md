Rick and Morty Character List App

Esse repositório compartilha um aplicativo mobile simples, desenvolvido em **JavaScript** (utilizando React Native com Expo). Ele permite que o usuário visualize uma **lista de personagens** da aclamada série "Rick and Morty" consumindo a **The Rick and Morty API**. O foco inicial é no **consumo de API** (Axios), gerenciamento de estado de *loading* e navegação (React Navigation).

A base do código atende aos **Requisitos 1 e 2** da atividade, focando na estruturação do projeto e na criação da Tela de Listagem. Mais informações sobre a continuação do projeto (Tela de Detalhes) estarão disponíveis em entregas futuras.

As tecnologias usadas foram:
- Java Script
- React Native
- Expo
- Axios

---

Para clonar o repositório será necessário o seguinte comando:

````
git clone https://github.com/Pyetro7007/PAM_APIRickAndMorty_PyetroFabricioPeterlini.git](https://github.com/Pyetro7007/PAM_APIRickAndMorty_PyetroFabricioPeterlini.git
````

Para clonar o repositório será necessário o seguinte comando:

````
cd PAM_APIRickAndMorty_PyetroFabricioPeterlini
````

Após acessar, você deve instalar o node_modules e o package-lock.json usando o comando:

````
npm install
````

Para executar o aplicativo, será necessário esse comando:

````
npx expo start --tunnel
````

Após executar esse comando, aparecerá um QRcode, que deve ser lido no aplicativo Expo Go.

Obs: É necessário ter instalado o Node.js no computador.
